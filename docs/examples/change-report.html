Architecture

Added connections

  • PR or branch changes → Change analysis: Reads the frozen diff and the corresponding source versions.
  • Change analysis → Report renderer: Provides structured facts, diagram connections, and validation results.
  • Report renderer → Worklog report: Writes a self-contained HTML file into the related worklog.

Unchanged connections

  • PR or branch changes → Code review: The reviewer receives the requested code change.
  • Code review → Findings in chat: The reviewer returns actionable findings in chat.
